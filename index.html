Latihan 19 · Kata Nama Terbitan · การวิเคราะห์คำ

แยกคำกลับ:
Kata Terbitan → คำมูล + หน่วยคำเติม

รอบนี้ทำย้อนกลับ — จากคำที่เติมหน่วยคำแล้ว ให้แยกกลับเป็นคำมูล ระบุหน่วยคำเติม และเขียนความหมายภาษาไทย

📋 คำชี้แจง

  1. โจทย์แต่ละข้อเป็น Kata Terbitan (คำที่เติมหน่วยคำแล้ว) ให้แยกออกเป็น 3 ช่อง:
    • Kata Dasar — คำมูล/รากศัพท์เดิม
    • Imbuhan — หน่วยคำเติมที่ใช้ (อาจเป็น peN- อย่างเดียว, -an อย่างเดียว, หรือหน่วยคำเติมวงล้อมอย่าง peN-...-an, ke-...-an, per-...-an)
    • ความหมายภาษาไทย — คำแปลของคำ Kata Terbitan นั้น
  2. คำในชุดนี้ไม่ได้ใช้หน่วยคำเติมแบบเดียวกันทั้งหมด — บางคำเป็นคำนามผู้กระทำ (peN-), บางคำเป็นคำนามกระบวนการ (peN-...-an), บางคำเป็นคำนามคุณสมบัติ (ke-...-an) และบางคำใช้ per-...-an ซึ่งเป็นคนละกลุ่มกับ peN- ต้องสังเกตให้ดี
  3. พิมพ์คำตอบทั้ง 3 ช่องแล้วกด "ตรวจคำตอบ" หรือ Enter — แก้ไขและตรวจใหม่ได้ไม่จำกัดจำนวนครั้ง
  4. ผลตรวจนับตามจำนวนช่องที่ถูก: 🟢 ถูกครบ 3 ช่อง · 🟡 ถูกบางช่อง (ระบบจะบอกว่าช่องไหนต้องแก้) · 🔴 ยังไม่ถูกเลย (ระบบเฉลยให้ทั้งหมด)
  5. กด "💡 ต้องการคำใบ้?" รายข้อ หรือปุ่ม "↺ ล้างคำตอบ" เพื่อเริ่มทำใหม่ได้ตลอดเวลา

ชนิดหน่วยคำเติมที่พบในชุดนี้
คำในชุดนี้มีหน่วยคำเติมหลายกลุ่มปนกัน ไม่ใช่ peN- อย่างเดียว
peN- (ผู้กระทำ)เติมหน้าอย่างเดียว ไม่มี -an — เช่น tulis → penulis
-an (เดี่ยว)เติมท้ายอย่างเดียว ไม่มีคำนำหน้า — เช่น makan → makanan
peN-...-anวงล้อมหน้า-หลัง สร้างคำนามกระบวนการ — เช่น didik → pendidikan
ke-...-anวงล้อมหน้า-หลัง สร้างคำนามคุณสมบัติ/นามธรรม จากคำคุณศัพท์ — เช่น bersih → kebersihan
per-...-anวงล้อมหน้า-หลัง คนละกลุ่มกับ peN- ใช้กับคำที่เกี่ยวข้องกับการค้า/สถาบัน — เช่น dagang → perdagangan
pe-...-an (ยกเว้น)คำยกเว้นทางประวัติศาสตร์ — เช่น kerja → pekerjaan (ไม่ใช่ pengerjaan)
